# 🚀 HTTP API V2 MIGRATION - QUICK DEPLOYMENT GUIDE

REST API (V1) → HTTP API (V2) Serverless Migration

═══════════════════════════════════════════════════════════════════════════════

✅ CAMBIOS REALIZADOS EN serverless.yml

1. Logs: restApi → httpApi (con formato JSON)
2. Provider: Agregar bloque httpApi con CORS
3. Eventos: http: {...} → httpApi: '*'
4. URLs: ApiGatewayRestApi → HttpApi (sin /stage)
5. Remover: ApiGatewayRole (no necesaria)

Archivo: backend/serverless.yml (ACTUALIZADO)

📋 DEPLOYMENT STEPS

1. UPDATE SSM PARAMETER (URL sin stage)
   ```bash
   aws ssm put-parameter \
     --name /heavy-freight/prod/CORS_ORIGIN \
     --value "https://app.example.com" \
     --overwrite
   ```

2. DEPLOY LAMBDA
   ```bash
   cd backend
   serverless deploy --stage prod --region us-east-1
   ```

3. GET NEW ENDPOINT
   ```bash
   serverless info --stage prod
   # Buscar: endpoint: https://xxxxx.execute-api.us-east-1.amazonaws.com
   ```

4. TEST HEALTH (sin stage en URL!)
   ```bash
   curl https://xxxxx.execute-api.us-east-1.amazonaws.com/health/live
   # Esperado: {"status": "alive"}
   ```

5. MONITOR FIRST HOUR
   - CloudWatch Logs: /aws/http-api/...
   - Error rate debe ser < 0.5%
   - Latency p99 < 1000ms
