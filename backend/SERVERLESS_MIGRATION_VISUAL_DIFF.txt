2. HTTP API CONFIGURATION (Lines 24-45) - NEW BLOCK
════════════════════════════════════════════════════════════════════════════════

❌ BEFORE (REST API):
```yaml
# No httpApi block (CORS configured per endpoint)
```

✅ AFTER (HTTP API):
```yaml
  httpApi:
    payload: '2.0'
    cors:
      allowedOrigins:
        - ${ssm:/heavy-freight/${self:provider.stage}/CORS_ORIGIN~true, 'http://localhost:4200'}
      allowedHeaders:
        - Content-Type
        - Authorization
        - X-Requested-With
        - X-Correlation-ID
      allowedMethods:
        - GET
        - POST
        - PUT
        - PATCH
        - DELETE
        - OPTIONS
      allowCredentials: true
      maxAge: 600
      exposedHeaders:
        - X-Correlation-ID
        - X-RateLimit-Remaining
```

💡 Change: Centralized CORS configuration (cleaner, more maintainable)

════════════════════════════════════════════════════════════════════════════════
3. API FUNCTION - EVENTS (Lines 100-102)
════════════════════════════════════════════════════════════════════════════════

❌ BEFORE (REST API):
```yaml
  api:
    handler: wsgi.handler
    events:
      - http:                    # Event 1: Root path
          path: /
          method: ANY
          cors: true
      - http:                    # Event 2: Proxy path (all routes)
          path: /{proxy+}
          method: ANY
          cors: true
```

✅ AFTER (HTTP API):
```yaml
  api:
    handler: wsgi.handler
    events:
      - httpApi: '*'  # Single event handles ALL routes and methods
```

💡 Change: Single event with wildcard (simpler, more efficient)
📊 Impact: Less CloudWatch execution, faster cold start
